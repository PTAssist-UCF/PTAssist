# Docs

Project documents that are not tied to one service: exercise specs, test data plan, security checklist, accuracy targets, and evaluation reports.

| Document | What it covers |
| --- | --- |
| [`analysis-result.md`](analysis-result.md) | The analysis result shared by the AI service, backend, and frontend: every field, error codes, scoring, feedback, clip limits, and the decisions behind them |
| [`analysis-result-examples/`](analysis-result-examples/) | Example results, one for each kind of result (listed in `analysis-result.md`, Examples) |
| [`exercises/`](exercises/) | One spec per exercise: camera setup, key joints, what counts as a rep or hold, form rules, and feedback wording |
| [`success-criteria.md`](success-criteria.md) | The accuracy targets each exercise analyzer must meet, how they are measured, and how many test clips that needs |
| [`test-data-plan.md`](test-data-plan.md) | How test videos are recorded, labeled, and stored (team OneDrive, never git), the volunteer consent note, and the dataset license check |
